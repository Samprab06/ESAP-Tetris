# Header Files

Project interface definitions and declarations.

## Files

- **main.hpp** - Pin definitions, constants, global configuration
- **logic.h** - Game state, piece data structures, core game logic
- **display.h** - TFT display rendering functions
- **audio.h** - WAV audio playback functions
- **sdcard.h** - SD card file I/O operations
- **globals.hpp** - Global variable declarations (legacy)
